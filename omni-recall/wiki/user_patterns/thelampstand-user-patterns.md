# User Patterns & Devotional Archetypes

## Primary User Personas

1. **The Contemplative Seeker**:
   - Values silence, lectio divina, and deep unhurried scripture engagement.
   - Dislikes gamification and notification spam. Uses Gentle Mode.
2. **The Morning Devotional Reader**:
   - Spends 3-5 minutes daily on Daily Light while preparing for work or during a commute.
   - Listens to audio narration and saves key verses to favorites.
3. **The Small Group Teacher / Pastor**:
   - Uses Sermon Mode to study homiletic outlines, biblical cross-references, and modern application questions.
4. **The Distressed / Wrestling Believer**:
   - Uses the Burning Bush Agent during grief, burnout, anxiety, or doubt.
   - Requires comforting Scripture and gentle pastoral presence without judgment.
