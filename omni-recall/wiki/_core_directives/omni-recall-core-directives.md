# Omni-Recall Core Directives

## Purpose
Omni-Recall preserves continuity across development sessions, prevents cognitive drift, and ensures adherence to APEX enterprise standards.

## Directives
1. **Never Invent or Assume**: Base all statements and architectural choices on real code, tests, and git metadata in the current session.
2. **Deterministic File Organization**: Organize facts cleanly into wiki nodes, decision records (ADRs), and correction logs.
3. **Compound Learning**: Turn every bug fix and review comment into an institutional regression shield.
4. **Honest Boundaries**: Distinguish clearly between active implemented capabilities and prospective roadmap items.
