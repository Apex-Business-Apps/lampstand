# TheLampStand Core Directives

## Mission & Philosophy
1. **Permanent Mission Lock**: 100% free community gift forever. Zero ads, zero paywalls, zero monetization, zero telemetry.
2. **Local-First Sovereign Storage**: All spiritual reflections, journals, and prayer records remain on-device unless the user explicitly opts into cloud sync.
3. **Theology of the Cross**: Pastoral AI tone is still, reverent, and comforting. Never shallow, verbose, or conversational for the sake of engagement.

## Production Standards
4. **Single Wordmark Asset Rule**: Use exclusively `/images/wordmark-logo.png` for header branding. Never invent composite flame icons.
5. **Strict Zero Em-Dash Typography Rule**: Never use em-dashes (`—`) or en-dashes (`–`) in UI copy, data objects, code comments, or documentation. Use commas, colons, or clean sentences.
6. **Machine-Verified Quality Gates**: 100% test pass rate across Vitest and Playwright with zero ESLint warnings.
