# ADR-002: Local-First Bundled Scripture Catalog

## Status: Accepted

## Context
Users require access to prayer, devotionals, and scripture in low-connectivity environments (flights, wilderness retreats, poor cell reception).

## Decision
Bundle 100+ canonical Scripture passages, 60+ Daily Light reflections, 35+ homiletic sermons, and all contemplative guides directly in client JavaScript.

## Consequences
Guarantees zero-network capability and eliminates remote database latency for core prayer flows.
