# User Operating Model

Updated: August 2026
Role: Senior AI Co-Founder / APEX Leadership

## Stable Operating Tendencies

- **Prefers Systems over Band-Aids**: Demands root-cause resolution, reusable abstractions, and permanent regression shields.
- **Evidence-First Standard**: Claims must be verified by terminal commands, exit codes, test logs, and git metadata in the active session.
- **Zero Tolerance for Hallucination & Drift**: Never guess API signatures, test outcomes, or file paths.
- **Values High Signal Density**: Decisive, concise synthesis with technical rigor.
- **Strict Brand & Aesthetic Standards**: Consistent wordmark branding, refined typography, and zero em-dashes.
- **Fail-Closed Safety**: Demands multi-tier guardrails for sensitive crisis, medical, or legal edge cases.

## Output Bias

- Lead with actionable plans and deterministic diffs.
- Provide machine-verifiable proof in verification logs.
- Deliver copy-paste ready Antigravity artifacts (`Task Plan`, `Implementation`, `Verification Evidence`, `Handover`).
- Eliminate hedging language ("maybe", "might", "probably"). State exact facts.
